Cheatsheet & Glossary

Reach for this page instead of re-reading a chapter. It assumes the explanations already happened; this is only the reference — the default prefix throughout is C-b (Ctrl-b), and prefix below always means "press C-b, release, then press the next key."

Sessions

Command line

tmux new -s NAME
create a new named session
tmux new -A -s NAME
attach if NAME exists, else create it
tmux ls
list sessions
tmux attach -t NAME
attach to a session
tmux attach -t NAME -r
attach read-only (watch, can't type)
tmux attach -t NAME -d
attach, detaching any other client first
tmux has-session -t NAME
exit 0 if NAME exists, else 1
tmux kill-session -t NAME
kill one session
tmux kill-server
kill every session, no confirmation, no undo
tmux rename-session NAME
rename the current session

Prefix bindings

prefix d
detach from the session
prefix $
rename the current session
prefix s
choose a session from a list
prefix ( / )
switch to previous / next session

Configuration essentials

The starter ~/.tmux.conf

set -s escape-time 10
server option; kills the Vim-Esc lag
set -g mouse on
click, drag-resize, scroll into copy mode
set -g history-limit 50000
default 2000; only new panes see it
set -g base-index 1
windows start at 1, not 0
setw -g pane-base-index 1
panes start at 1 too
set -g renumber-windows on
closing a window closes its number gap
set -g focus-events on
lets Vim/Neovim autoread on focus return
tmux source-file ~/.tmux.conf
reload config into a live server

Scope, in one line each

set-option -s
server — whole process, one namespace
set -g
session — default every session inherits
set (no -g)
this session only
setw -g
window — default every window inherits
setw (no -g)
this window only

Key bindings & command mode

Working with bindings

bind-key [-nr] [-T table] key cmd
add a binding
unbind-key [-n] [-T table] key
remove a binding
-n
shorthand for -T root: no prefix needed
-r
repeatable within repeat-time (500ms default)
tmux list-keys -T prefix
ground truth: what's actually bound
prefix :
command-prompt — type any tmux command directly

Remapping the prefix

unbind C-b
remove the default prefix binding
set -g prefix C-a
set the new prefix key
bind-key C-a send-prefix
required — sends a literal C-a through

Scripting primitives

Targets & introspection

-t session:window.pane
e.g. -t work:1.2
tmux display-message -p '#{...}'
print one live format value to stdout
tmux if-shell "test" cmd [else]
conditional; blocks until test finishes
tmux run-shell [-b] cmd
background shell command, no new window
tmux wait-for CH / wait-for -S CH
block / signal a rendezvous channel

A minimal setup script

tmux new-session -d -s NAME
create detached, so more setup can follow
tmux split-window -h -c "#{pane_current_path}"
split into the live directory
tmux send-keys -t T 'cmd' C-m
type and submit — C-m is required
tmux select-layout tiled
a consistent final arrangement

Plugins & persistence

TPM

set -g @plugin 'user/repo'
declare a plugin
run '~/.tmux/plugins/tpm/tpm'
must be the last line of tmux.conf
prefix I
fetch and install new plugins
prefix U
update installed plugins
prefix alt-u
remove plugins no longer declared

tmux-resurrect / tmux-continuum

prefix Ctrl-s / Ctrl-r
save / restore manually
@resurrect-processes '...'
allow-list of programs to relaunch, not just a shell
@resurrect-capture-pane-contents 'on'
also save visible scrollback text
@continuum-save-interval 'N'
autosave every N minutes
@continuum-restore 'on'
auto-restore on server start only, never on reload

Debugging

Ground truth first

tmux list-keys -T prefix
what a key actually does right now
tmux show-options -g
actual current global session options
tmux show-options -g -w
actual current global window options
echo $TERM / echo $TMUX
sanity-check color and nesting state
tmux -v / tmux -vv
verbose logging to files in the cwd
tmux -2
force 256-color assumption

Glossary

Core terms

server
the single background tmux process holding every session's actual state, independent of any client
client
one attached terminal talking to the server — a session can have more than one at once (ch. 17)
session
a named collection of windows, the unit you attach to and detach from
window
one tab within a session, shown in the status line, holding one or more panes
pane
one rectangular subdivision of a window, running one shell or program
target
the session:window.pane address a command acts on
format
a #{...} string tmux expands against live state — status line, command output, scripting
command mode
the prefix : prompt where any tmux command can be typed directly
key table
a named set of key→command bindings (root, prefix, copy-mode, or custom)
