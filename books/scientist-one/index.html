Chain-of-Evidence, and what it costs to make an AI scientist's claims checkable

Seven chapters Voice: The Crafter arXiv 2605.26340

Autonomous research agents already write competitive solutions and professional-looking papers. That is not the hard part anymore. The hard part is that a paper can read perfectly and still be lying to you — a citation that does not exist, a score nobody can reproduce, a method description that quietly diverges from the code that actually ran. ScientistOne is Google Cloud AI Research's answer: a research system built so that every claim it makes carries its own receipt, from the first PDF it reads to the last sentence it writes.

This book builds that idea one piece at a time — the failure modes that motivate it, the Chain-of-Evidence framework that formalizes "traceable," the three-stage pipeline that keeps the evidence trail intact by construction, and the CoE Audit that turns "trust us" into four numbers you can check yourself. We close by reading the actual results: zero hallucinated references across 337 checked, and what that number costs to earn.

There is also a cheatsheet — the framework, the pipeline, and the four audit checks on one page.
