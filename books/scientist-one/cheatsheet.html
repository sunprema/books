The whole thing, one page

Chain-of-Evidence, the ScientistOne pipeline, and the CoE Audit's four checks — for when you want the shape of the argument without the chapters.

The thirty-second summary

Autonomous research agents write competitive, professional-looking papers that still fail basic verification: fabricated citations, unreproducible scores, method descriptions that diverge from the code. Chain-of-Evidence (CoE) requires every claim to trace to a real grounding source. ScientistOne maintains that trace by construction across three stages. The CoE Audit checks any system's output — baseline or not — with four uniform, post-hoc checks.

A paper that reads well is not evidence the paper is right.

Three failure modes CoE targets

  • Fabricated citations — plausible, nonexistent references
  • Unreproducible scores — a headline number a fresh run doesn't reproduce
  • Method-code divergence — prose describing an algorithm the code doesn't run

CoE claim types and their trace targets

Claim typeMust trace to
Citationa real source in a scholarly database, accurately characterized
Numericala recorded run output
Methodologicalthe corresponding implementation code

The ScientistOne pipeline

  1. Literature review — Problem Investigator reads up to 100 full-text PDFs per topic → grounded experiment brief
  2. Solution discovery — Discovery Engine's parallel explore-exploit search tree → scored, constraint-respecting solution
  3. Paper writing — Claim Verifier checks every claim against its declared evidence source before it ships

The CoE Audit's four checks

  1. I1 Score verificationreported score vs. independent re-run
  2. I2 Specification violationsolves the task, doesn't exploit the evaluator or read answer files
  3. I3 Reference verificationevery citation checked against real sources
  4. I4 Method-code alignmentpaper's method description matches the code
