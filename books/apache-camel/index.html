How this book is organized

Seven parts, in the order an integration developer actually needs them: Foundations (why integration is hard, and Camel's vocabulary), First Routes (a working project, then the DSLs), Messages (the Exchange, transformation, data formats, validation), Core Patterns (routing, splitting, enrichment, reliable delivery, async), Real Systems (files, HTTP, databases, messaging, choosing components), Reliability and Operations (errors, redelivery, testing, observability, config, deployment), and a two-chapter Capstone that builds one order-processing integration and then hardens it for production.
