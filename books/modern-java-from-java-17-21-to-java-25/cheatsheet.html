The three claims to correct in code review
  1. “Structured concurrency is in Java 25.” It is in preview. Needs --enable-preview; the API changes again in JDK 26.
  2. “Compact object headers shrink our heap on 25.” Only with -XX:+UseCompactObjectHeaders. Not on by default.
  3. “Avoid synchronized with virtual threads.” True on 21–23. Obsolete from 24 (JEP 491). Native frames still pin.

Records

public record Money(String ccy, long minor) {
    public Money {                          // compact constructor
        Objects.requireNonNull(ccy);
        ccy = ccy.toUpperCase(Locale.ROOT);   // normalize by reassigning
    }
    static Money zero(String c) { return new Money(c, 0); }
}
  • Accessor is ccy(), not getCcy().
  • Implicitly final; extends java.lang.Record; may implement interfaces.
  • No extra instance fields. Static members and methods are fine.
  • Shallowly immutable — defensively copy mutable components: values = List.copyOf(values);
  • Local records are allowed inside a method.

Sealed types & pattern matching

sealed interface Result<T> permits Ok, NotFound, Failed {}

switch (r) {
    case null                    -> "none";      // else NPE
    case Ok(Product p) when p.free() -> "gift";      // guard first
    case Ok(Product p)          -> p.sku();
    case NotFound(String sku)   -> "404 " + sku;
    case Failed(String why)     -> "502 " + why;
}   // no default: exhaustive over the sealed set
  • Permitted subtypes must be final, sealed or non-sealed, and in the same module.
  • permits may be omitted if all subtypes are in the same file.
  • Never add default to a sealed switch — it disables exhaustiveness checking.
  • Broader pattern before narrower = compile error (dominance).
  • Record patterns nest; var allowed for components you ignore.

Virtual threads

try (var ex = Executors.newVirtualThreadPerTaskExecutor()) {
    var f = ex.submit(() -> blockingCall());
    return f.get();
}                                             // close() awaits all tasks

Thread.ofVirtual().name("job").start(runnable);
  • Never pool them. One per task.
  • Do replace the cap the pool was giving you: Semaphore sized to the scarce resource.
  • Still pins: native frames (JNI, FFM downcalls), class initializers.
  • No longer pins from JDK 24: synchronized.
  • CPU-bound work does not speed up — carriers = CPU count.
  • Find pinning: jfr print --events jdk.VirtualThreadPinned app.jfr

Structured concurrency Preview on 25

// javac --release 25 --enable-preview   /   java --enable-preview
try (var scope = StructuredTaskScope.open(
         Joiner.<Object>awaitAllSuccessfulOrThrow(),
         cf -> cf.withName("lookup")
                 .withTimeout(Duration.ofMillis(500)))) {

    var a = scope.fork(() -> one());
    var b = scope.fork(() -> two());
    scope.join();                    // fork all, join once, THEN get()
    return merge(a.get(), b.get());
}
allSuccessfulOrThrow()
all succeed; join() → Stream<Subtask<T>> on 25 (List<T> on 26)
awaitAllSuccessfulOrThrow()
all succeed, mixed result types; read per subtask
anySuccessfulResultOrThrow()
first success wins; throws only if all fail
awaitAll()
wait for all, no failure policy
allUntil(pred)
stop when the predicate says so
  • Subtask.get() only after join(), only if it succeeded — else IllegalStateException.
  • Cancellation is an interrupt: never swallow InterruptedException without Thread.currentThread().interrupt().

Scoped values Final Java 25

static final ScopedValue<Ctx> CTX = ScopedValue.newInstance();

ScopedValue.where(CTX, ctx).run(() -> handle(req));   // or .call(...)
Ctx c = CTX.get();                       // NoSuchElementException if unbound
if (CTX.isBound()) { ... }               // optional read
  • No set(). Rebind by nesting another where(...).run(...).
  • orElse(null) is not allowed in the final API.
  • Inherited by subtasks forked in a StructuredTaskScope — not by tasks handed to an arbitrary executor.

FFM API Final Java 22

Linker linker = Linker.nativeLinker();
MethodHandle strlen = linker.downcallHandle(
    linker.defaultLookup().find("strlen").orElseThrow(),
    FunctionDescriptor.of(ValueLayout.JAVA_LONG, ValueLayout.ADDRESS));

try (Arena a = Arena.ofConfined()) {
    long n = (long) strlen.invokeExact(a.allocateFrom("hi"));
}
ofConfined()
one thread, freed on close() — the default
ofShared()
any thread, freed on close()
ofAuto()
freed by the GC
global()
never freed
  • Errors you get instead of a crash: IllegalStateException (closed), WrongThreadException, IndexOutOfBoundsException.
  • invokeExact needs exact static types — the (long) cast is part of the signature.
  • Handle = constant. Arena = per-call resource. Never the reverse.
  • Run with --enable-native-access=ALL-UNNAMED; jextract is a separate download.

JMH, minimally

@State(Scope.Benchmark) @Fork(2)
@Warmup(iterations = 5, time = 1) @Measurement(iterations = 5, time = 1)
@BenchmarkMode(Mode.AverageTime) @OutputTimeUnit(TimeUnit.NANOSECONDS)
public class Bench {
    @Benchmark public Instant parse() { return Instant.parse(input); }
}
  • Return the result (or use a Blackhole) or the JIT deletes your benchmark.
  • Never a hand-rolled System.nanoTime loop: no warm-up, no fork, dead-code elimination.
  • JMH answers method questions. Service questions need a load test plus JFR.

Migration checklist

  1. DTOs and value objects → records. Add compact-constructor validation. Check your serialization library handles records.
  2. Closed sets of outcomes → sealed interface + records. Convert switches, delete every default over a sealed type.
  3. Thread pools for I/O → virtual threads, and a Semaphore at the same time, keeping the old pool size as its initial value.
  4. Audit for pinning with JFR. Remember: synchronized is fine from 24; native calls are not.
  5. Context parameters / ThreadLocal → scoped values (final, safe to ship).
  6. Fan-outs needing cancellation and a deadline → structured concurrency — decide about --enable-preview first, and hide it behind your own interface.
  7. JNI → FFM, only where there is no pure-Java option. Arena per call, handle static, --enable-native-access in the launch script.
  8. Turn on JFR permanently. Add an AOT cache to the build. Evaluate -XX:+UseCompactObjectHeaders under load.
  9. One change at a time, with a written prediction and a measurement between each.
If you remember nothing else
  1. Records and sealed types move whole classes of bug from runtime to compile time. Adopt them first; they never churn.
  2. Virtual threads make blocking cheap — and delete the back-pressure you did not know you had. Bound the resource explicitly.
  3. Scoped values are final on 25. Structured concurrency is not, and changes again on 26.
  4. FFM turns native use-after-free into an exception. Use it only when there is no Java alternative.
  5. Compact object headers need the flag. CPU-time profiling is experimental and Linux-only.
  6. Predict, change one thing, measure.
