Read this if

You write Java for a living, you are on 17 or 21 today, and someone has put “move to 25” on a roadmap. You do not need the language explained. You need to know what is genuinely new, what is final versus preview, and where each feature bites in production.

Your Brain on “a new Java version”

Most version-upgrade material is a changelog: a flat list where a language feature you will use every day sits beside a JVM flag you will never type. That flattening is why upgrades feel like homework.

This book is ordered by what it changes in your code. Chapters 1–2 change the shapes you declare. Chapters 3–4 change how you spend a thread. Chapters 5–6 change what you can reach and what you can see. Chapter 7 makes you do all of it at once, to one small service.

One promise about versions

Every feature here carries the JDK version it became final in. Anything still preview on Java 25 is labelled preview at every mention — there is exactly one such feature in this book, and Chapter 4 is blunt about what that costs you.

What this book deliberately leaves out

Java basics, OOP, generics, collections, streams and lambdas. Detailed JPMS coverage. A full garbage-collector comparison. The Vector API and the Class-File API. An exhaustive preview-feature catalogue. Framework tutorials for Spring, Quarkus or Micronaut. All of that is well covered elsewhere, and none of it is what changed.
