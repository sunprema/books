Conclusion

Where to go next

You have the working set: ownership, borrowing, enums and matching, traits and generics, iterators, errors as values, and enough Cargo to ship. That is genuinely most of the language you will use day to day. Here is what to read when you want more, and how to keep it.

The next books

The Rust Programming Language
doc.rust-lang.org/book — "the book". Free, official, and much more thorough than this one. Chapters 15–20 in particular go well past where we stopped. Read it next.
Rust by Example
doc.rust-lang.org/rust-by-example — the same ground as runnable snippets. Good if you learn by editing rather than reading.
The Standard Library docs
doc.rust-lang.org/std — unusually well written, and the right reflex when you wonder whether a method exists. It usually does.
The Rust API Guidelines
rust-lang.github.io/api-guidelines — a checklist for what a well-shaped public interface looks like. Short, and it will change how you name things.
The Rustonomicon
doc.rust-lang.org/nomicon — unsafe, properly. Read it before you write unsafe, not after.

How to keep learning

Read other people's crates. Rust source is unusually readable, and docs.rs puts a "source" link beside every item. When a library does something you didn't know was possible, the implementation is one click away.

Follow the release notes. A new stable ships every six weeks — 1.97.1 was July 2026 — and the notes are short. Rust changes by accretion, not by breakage, so twenty minutes every couple of months is genuinely enough to stay current. Editions arrive every three years or so; 2024 is the one you're on.

Contribute something small. A documentation fix, a failing test, an example. Rust's ecosystem is welcoming to that, and reading review comments on your own code is faster than any book.

One last thing

Rust is hard at the start in a way that is easy to mistake for the language being hostile. It isn't. The compiler is asking you questions you were previously allowed to leave unanswered: who owns this, how long does it live, what happens when it isn't there. Those questions were always in your program. Rust just makes you write down the answers.

Ownership clicks all at once, usually a week or two in, and afterwards you can't remember what was difficult about it.

When that happens, the payoff is a kind of confidence that is hard to get elsewhere: if it compiles, whole categories of failure are simply gone. Not "unlikely" — gone. It is worth the first afternoon.

Go build something.
