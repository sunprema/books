Cheatsheet

The 30-second summary

Every value has one owner. Passing it moves it unless it's Copy. Lend it instead with & (many readers) or &mut (one writer, no readers). When the owner's scope ends, the value drops. Failure is a Result you return, not an exception you throw. Everything else is consequence.

Bindings and types

let x = 5;              // immutable
let mut y = 5;          // mutable
let x = "now a str";     // shadowing: new binding, new type
const N: u8 = 3;         // compile-time, type required

Overflow: panics in debug, wraps in release. Say what you mean with checked_, wrapping_, saturating_.

Control flow

loop { break value; }                 // break carries a value
while c { }   for i in 0..5 { }       // 0..=5 is inclusive

match v {
    0 => …,
    1..=9 => …,
    x if x % 2 == 0 => …,     // guard
    _ => …,                     // exhaustive or it won't compile
}

if let Some(x) = opt { }
let Some(x) = opt else { return; };   // else must diverge

Structs, enums, impls

#[derive(Debug, Clone, PartialEq, Default)]
struct S { a: u32, b: String }
struct Meters(f64);          // newtype

enum E { Unit, Tup(i32), Named { w: f64 } }

impl S {
    fn new() -> Self { Self::default() }   // associated fn
    fn get(&self) { }                     // reads
    fn set(&mut self) { }                 // mutates
    fn into_b(self) -> String { self.b }   // consumes
}

Iterators

.iter()      // &T
.iter_mut()  // &mut T
.into_iter() // T — consumes the collection

// adaptors (lazy)
map filter filter_map flat_map enumerate zip
chain rev take skip take_while windows chunks

// consumers (drive it)
collect sum count fold find any all min max for_each

collect() is decided by the annotation. Into Result<Vec<_>, _> it short-circuits at the first Err; into Vec<Result<_,_>> it keeps everything.

Traits and generics

fn f<T: Display + Clone>(x: &T) { }
fn f(x: &impl Display) { }
fn f<T>(x: &T) where T: Display { }
fn g() -> impl Iterator<Item = u32> { }   // opaque concrete type
let v: Vec<Box<dyn Trait>> = …;              // dynamic dispatch

Generics monomorphise (fast, bigger binary); dyn uses a vtable (one copy, one hop). Orphan rule: the trait or the type must be yours.

Smart pointers

TypeFor
Box<T>one owner on the heap; recursive types; dyn
Rc<T>many owners, one thread
Arc<T>many owners, across threads
RefCell<T>borrow check at run time (panics)
Mutex<T>one writer across threads
Weak<T>non-owning handle; breaks Rc cycles

Single-thread shared-mutable: Rc<RefCell<T>>. Multi-thread: Arc<Mutex<T>>. Write Rc::clone(&x), not x.clone().

Concurrency

let h = thread::spawn(move || work());
let r = h.join().unwrap();

let (tx, rx) = mpsc::channel();
let tx2 = tx.clone();  drop(tx);   // or rx never ends
for msg in rx { }

let c = Arc::new(Mutex::new(0));
*c.lock().unwrap() += 1;         // guard drops = unlock

#[tokio::main] async fn main() { f().await; }

Send = movable across threads. Sync = &T shareable. A future does nothing until polled; the runtime comes from a crate (Tokio).

Gotchas

  • A trailing semicolon changes the return type to ().
  • s.len() is bytes, not characters.
  • Integer overflow panics in debug, wraps in release.
  • Forgetting drop(tx) hangs a channel receiver forever.
  • Holding a MutexGuard across .await deadlocks.
  • #[derive(Copy)] fails if any field owns a heap allocation.
  • mod declares a module once; use only shortens a path.
  • x.clone() on an Rc is cheap — but it reads like a deep copy.
