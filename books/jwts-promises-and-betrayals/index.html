JWTs:
Promises
and Betrayals

A JSON Web Token makes exactly one promise, and it is narrower than almost everyone assumes. This book takes each mechanism apart, asks how an attacker would subvert it, and then rebuilds the defense from what the answer reveals.

Eight chapters · Grounded in RFC 7519, RFC 7515 & BCP 225

A signature answers one question: did the holder of a particular key produce these exact bytes? Every other question you are asking it is one you have to answer yourself.

Read it in order — each chapter's defense depends on the previous chapter's attack. Chapter 8 collapses the whole book into a checklist you can hold against your own verification code.
