PromptSpec
for Autonomous Agents

Nine chapters Voice: The Crafter Set in Swiss

A prompt written for a human in the room can afford to be vague — you are there to answer. A prompt that fires at 3 a.m. cannot. PromptSpec is a declaration language for exactly that situation: every decision an agent might otherwise improvise — what it may use, what it must never do, what to return when it is unsure, how to undo what it already did — is written down before the run, in a file that is read but never executed.

This book works through the language a piece at a time and then reads one real specification that has already been corrected three times by production. That last part matters more than it sounds: the corrections are the argument.
