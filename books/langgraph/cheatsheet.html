StateGraph API

StateGraph(state_schema)
Create a graph builder. Pass a TypedDict or Pydantic BaseModel as the state schema.
.add_node(name, function)
Register a node. The function takes (state: State) → dict and returns a partial state update.
.add_edge(from_node, to_node)
Add a fixed edge. Multiple sources to one target creates a join barrier.
.add_conditional_edges(source, path_fn, path_map)
Route dynamically. path_fn(state) → str picks the next node. path_map maps return values to node names.
.compile(checkpointer=, interrupt_before=, interrupt_after=)
Build the executable graph. Returns a CompiledStateGraph with invoke(), stream(), ainvoke(), astream().
.set_node_defaults(retry_policy=, timeout=)
Apply default policies to all nodes. Per-node values override.

State Definition

class State(TypedDict):
    messages: Annotated[list, operator.add]  # reducer: append
    query: str                              # default: overwrite
    results: Annotated[list, operator.add]   # reducer: append
    step_count: int                          # default: overwrite

Keys without Annotated are overwritten by the last node to set them. Use Annotated[type, reducer_fn] to accumulate values.

Minimal Graph

def my_node(state: State) -> dict:
    return {"messages": ["hello"]}

builder = StateGraph(State)
builder.add_node("greet", my_node)
builder.add_edge(START, "greet")
builder.add_edge("greet", END)
graph = builder.compile()
result = graph.invoke({"messages": []})

Memory & Checkpointing

MemorySaver()
In-memory checkpointer for development. State persists across invocations within the same thread_id.
SqliteSaver / PostgresSaver
Production checkpointers. Durable across process restarts.
config={"configurable": {"thread_id": "abc"}}
Pass to invoke() or stream() to isolate conversations by thread.
graph.get_state(config)
Inspect the current state of a thread.
graph.update_state(config, values)
Modify state from outside the graph (for human-in-the-loop).
graph.get_state_history(config)
List all checkpoints for time-travel debugging.

Control Flow Patterns

Conditional routing
add_conditional_edges(src, path_fn, {"a": "node_a", "b": "node_b"})
Cycle / loop
Add an edge from node B back to node A. Use a state counter to break the loop.
Human-in-the-loop
compile(interrupt_before=["review"]) pauses before the review node. Resume with invoke(None, config) after updating state.
Dynamic interrupt
result = interrupt(value) inside a node. Sends value to the client; resumes with the client’s response as result.
Parallel fan-out
return [Send("worker", {"task": t}) for t in tasks] from a conditional edge path function.
Retry
add_node("n", fn, retry_policy=RetryPolicy(max_attempts=3))

Streaming Modes

"values"
Emit the full state after each node completes.
"updates"
Emit only the partial state update from each node.
"messages"
Stream LLM tokens as they are generated inside nodes.
"events"
Fine-grained event stream (node start/end, LLM calls, tool calls).
"custom"
Emit custom events from inside nodes via stream_writer.
for chunk in graph.stream(
    {"messages": [("user", "hello")]},
    stream_mode="updates"
):
    print(chunk)

Multi-Agent Patterns

Supervisor
One agent with tools that call specialist agents. The supervisor decides who works next.
Peer-to-peer
Agents share state and route to each other via conditional edges.
Subgraphs
A compiled graph added as a node in a parent graph. State maps between schemas.
Map-reduce
Use Send() to fan out to parallel workers, collect results via a reducer.

Prebuilt Components

MessagesState
Prebuilt state schema with a messages key and the add_messages reducer. Use for chat applications.
ToolNode
Prebuilt node that executes tool calls from the LLM’s response.
tools_condition
Prebuilt condition that routes to ToolNode if the last message has tool calls, otherwise to END.
create_react_agent(model, tools)
One-liner to build a complete ReAct agent graph with tool calling.

Deployment

langgraph dev
Local development server with API endpoints and studio UI.
LangGraph Platform
Managed cloud deployment. Handles scaling, persistence, and queuing.
Self-hosted
Deploy the LangGraph API server on your own infrastructure with Docker.
langgraph.json
Configuration file declaring the graph, dependencies, and environment variables for deployment.

When to Use What

Simple prompt → response
Plain LangChain. No graph needed.
Linear chain (A → B → C)
LangChain’s LCEL pipes or a simple StateGraph.
Tool-calling agent
create_react_agent or a two-node graph (chatbot + tools).
Stateful multi-turn with memory
StateGraph + MemorySaver with thread_id.
Human approval gates
StateGraph + interrupt_before / interrupt().
Multi-agent collaboration
StateGraph with subgraphs or supervisor pattern.
Complex pipeline with retries and error recovery
StateGraph with RetryPolicy, error handlers, and conditional edges.
