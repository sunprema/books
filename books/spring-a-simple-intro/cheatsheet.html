Quick Reference

Cheatsheet

Everything in the book, compressed. Spring Boot 4.1, Java 17+.

The 30-second version

Generate at start.spring.io → annotate a class @RestController → put rules in an @Service → extend JpaRepository for storage → @Valid the input → @RestControllerAdvice for errors → SecurityFilterChain for the login → ./mvnw package → java -jar.

Boot 4 gotchas

  • spring-boot-starter-web → spring-boot-starter-webmvc
  • Jackson 3: group id com.fasterxml.jackson → tools.jackson
  • Security 7: authorizeRequests() and .and() are removed
  • 4.1 removed layertools jar mode (use tools) and deprecated Derby
  • @MockBean → @MockitoBean

Persistence

java@Entity
class Task {
  @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
  private Long id;
  protected Task() { }        // required — so it can't be a record
}

interface TaskRepository extends JpaRepository<Task, Long> {
  List<Task> findByDoneTrue();
  List<Task> findByTitleContainingIgnoreCase(String s);
}

Free from JpaRepository: save · findById · findAll · deleteById · count · existsById. Derived queries are parsed at startup — a bad name fails the boot, not a request.

Security 7

java@Bean
SecurityFilterChain api(HttpSecurity http) throws Exception {
  return http
      .authorizeHttpRequests(auth -> auth      // NOT authorizeRequests
          .requestMatchers("/hello").permitAll()
          .anyRequest().authenticated())      // first match wins
      .httpBasic(Customizer.withDefaults())
      .csrf(csrf -> csrf.disable())          // stateless API only
      .build();
}

Lambda DSL is required in 7 — no .and(). Hash with BCryptPasswordEncoder. Basic auth sends credentials every request, so HTTPS only. Error dispatches are now authorized too, so permit /error if 401s appear from nowhere.

When it doesn't work

  • 404 on a new route — controller outside the main class's package tree
  • Validation ignored — missing @Valid
  • "no main manifest attribute" — running the un-repackaged JAR
  • Won't compile after upgrade — authorizeRequests/.and(), or -web vs -webmvc
  • Entity won't map — it's a record, or has no no-arg constructor
  • 401 on error pages — Security 7 authorizes error dispatches
