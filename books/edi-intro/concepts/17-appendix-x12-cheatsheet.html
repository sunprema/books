Common body segments

BEG
Beginning segment for purchase order. 01 transaction purpose (00 original), 02 PO type (SA stand-alone), 03 PO number, 05 date.
BIG
Beginning segment for invoice. 01 invoice date, 02 invoice number, 03 PO date, 04 PO number — the join back to the order.
BSN
Beginning segment for ship notice. 02 shipment identifier, 03/04 date and time.
REF
Reference identification. Qualifier + value; meaning is entirely contextual (DP department, BM bill of lading, VN vendor order number).
N1 / N3 / N4
Party loop. N1 entity code + name + id qualifier + id; N3 street; N4 city / state / postcode / country.
PO1
Purchase order baseline item. 01 line number, 02 quantity, 03 unit, 04 unit price, then repeating qualifier/value product-id pairs.
IT1
The 810's line item — same shape as PO1.
PID
Product description. 01 F = free-form, description in 05.
HL
Hierarchical level. 01 this loop's id, 02 parent id, 03 level code.
MAN
Marks and numbers — carries the SSCC-18 carton barcode in an 856.
CTT
Transaction totals. Line count; a free integrity check.
TDS
Total monetary summary on an invoice, in implied decimals.

Context is everything

REF and N1 mean different things in different transaction sets, and a qualifier list that is right for one partner may be wrong for the next. Treat this appendix as orientation; treat the implementation guide as truth.
