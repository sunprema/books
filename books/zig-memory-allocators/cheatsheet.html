Cheatsheet

Everything you need on one page. The interface, the allocators, when to use which, the patterns, and the gotchas.

Allocator Interface

std.mem.Allocator is a two-field struct: a pointer to an opaque context and a pointer to a VTable. The VTable has two function pointers:

alloc(self, len, ptr_align, ret_addr) ?[*]u8
Allocate len bytes with the given alignment. Returns null on failure.
resize(self, buf, buf_align, new_len, ret_addr) bool
Try to resize in place. Returns true on success, false if the allocator cannot resize without moving.
free(self, buf, buf_align, ret_addr) void
Return memory to the allocator. The buffer must have been obtained from the same allocator.

Convenience methods on Allocator that wrap the VTable:

alloc(T, n)
Allocate a slice of n items of type T.
create(T)
Allocate and return a pointer to a single T.
free(slice)
Free a previously allocated slice.
destroy(ptr)
Free a single item allocated with create.
dupe(T, slice)
Duplicate a slice, returning a new allocation.
realloc(slice, new_len)
Resize or reallocate a slice.

Standard Allocators

std.heap.page_allocator
Allocates whole OS pages via mmap/VirtualAlloc. Slow (~μs), no fragmentation, thread-safe. Use as a backing allocator.
std.heap.GeneralPurposeAllocator
Bucket-based allocator with safety checks: leak detection, double-free detection, use-after-free guard pages. Medium speed (~100s ns). The safe default.
std.heap.ArenaAllocator
Bump allocator that frees everything at once. Fast (~ns). Perfect for request/phase-scoped scratch memory.
std.heap.FixedBufferAllocator
Bump allocator over a caller-provided fixed buffer. Fast (~ns), no syscalls, bounded. Ideal for embedded and stack-backed use.
std.heap.c_allocator
Wraps libc malloc/free. Use exclusively for memory that crosses the C/Zig boundary.
std.testing.allocator
Instrumented allocator that fails the test on leaks or double-frees. Use in all tests.
std.heap.LoggingAllocator
Wrapper that logs every alloc/resize/free. Wrap any allocator to understand allocation patterns.

Decision Tree

  • Test code? → std.testing.allocator
  • C interop? → c_allocator
  • All freed at once? (request, frame, parse) → ArenaAllocator
  • Bounded, compile-time size? → FixedBufferAllocator
  • Many same-size objects? → Pool allocator (custom)
  • General use? → GeneralPurposeAllocator (start here, optimize later)

Common Patterns

  • defer cleanup — pair every allocation with defer allocator.free(buf) or defer list.deinit() immediately after the allocation.
  • errdefer — free memory on the error path when the caller will own the memory on success: errdefer allocator.free(buf).
  • Arena per-request — create an arena at the top of each request/frame, pass arena.allocator() to all functions, and defer arena.deinit() when the request ends.
  • Composition — wrap allocators with LoggingAllocator, FailingAllocator, or custom wrappers for metrics, quotas, and tracing. Each wrapper implements the same interface and delegates to the inner allocator.
  • Per-subsystem allocators — give each subsystem its own allocator for independent tracking and bulk teardown.

Gotchas

  • Never mix allocators. Memory allocated by one allocator must be freed by the same allocator. Mixing causes undefined behavior.
  • Arena + long-lived pointer = dangling. If you store a pointer from an arena into a long-lived structure, the pointer becomes invalid when the arena is reset or destroyed. Copy the data out first.
  • GPA is for safety, not speed. The GeneralPurposeAllocator prioritizes correctness: leak detection, double-free detection, guard pages. It is the right starting allocator, not the fastest one.
  • Most allocators are not thread-safe. Use ThreadSafeAllocator or per-thread allocators if you allocate from multiple threads.
  • FixedBufferAllocator cannot grow. When the buffer is full, the next allocation returns error.OutOfMemory. Size it carefully.

Key Types

std.mem.Allocator
The universal allocator interface. Two fields: ptr (opaque context) and vtable (function pointers).
std.heap.GeneralPurposeAllocator(config)
Configurable general-purpose allocator. Returns a struct; call .allocator() to get the interface.
std.heap.ArenaAllocator
Wraps a backing allocator. Call .init(backing), then .allocator(). Bulk-free with .deinit() or .reset().
std.heap.FixedBufferAllocator
Takes a []u8 slice. No backing allocator needed. Call .init(buf).
std.ArrayList(T)
Growable array. Takes an Allocator in .init(allocator). Clean up with .deinit().
std.HashMap(K, V, ...)
Hash map. Takes an Allocator. Also available as std.AutoHashMap(K, V) with default hash/eql.
