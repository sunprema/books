Which version this book uses

Every example and lab uses Oracle Database 19c, the long-term release most production sites still run. Where a thing only works in a newer release, or needs an extra paid option, the page says so.

Who this is for

You already know SQL and what a transaction is. This book is about running the database, not writing queries or clicking through an install. One made-up shop, an order-taking app, follows you from chapter to chapter.
