One rival, eight rounds

Every chapter fights the same opponent so you never relearn a scenario: Kohai, a release-notes sidekick. It reads a git repository, decides which commits matter, and drafts the notes. Chapter 1 shows why a chatbot cannot do this. Chapter 6 makes it work. Chapter 8 makes it survive Monday morning.

What you need

  • Enough Python to read a for loop and a dictionary. You do not need to be fluent.
  • pip install anthropic, and credentials the SDK can find in your environment.
  • Any git repository you are willing to point a program at. Yours will do.

Code samples use the Anthropic SDK and the model claude-opus-5. The ideas — the loop, the schema, the guardrail — are not vendor-specific; the exact field names are.
